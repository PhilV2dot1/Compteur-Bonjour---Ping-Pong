# Compteur-Bonjour---Ping-Pong

Contrat Celo : 0x39f27432088306FB4c70cD178ad9bc218B4507e3
Contrat Base : 0x1c01dDbbF42F29d62d48A16f282B2cc7256d1D36

Système de comptage :
Compteurs automatiques :


Compteur global : Toutes les interactions avec le contrat
Par utilisateur : Nombre d'interactions de chaque adresse
Par fonction : Quelle fonction est la plus utilisée
Historique complet : Toutes les interactions avec timestamp

Fonctions d'exemple :

direBonjour() - Retourne "Bonjour !"
incrementer() - Retourne votre nombre d'interactions
ping() - Retourne "Pong !"
laisserMessage() - Enregistre un message

Statistiques et analyses :
Informations individuelles :

obtenirMesInteractions() - Vos propres interactions
obtenirHistoriqueUtilisateur() - Historique détaillé d'un utilisateur
obtenirRang() - Votre position dans le classement

Statistiques globales :

obtenirStatistiques() - Vue d'ensemble complète
obtenirTopUtilisateurs() - Classement des plus actifs (top 10)
obtenirDernieresInteractions() - Les 10 dernières actions
obtenirActiviteRecente() - Stats 24h, 7j, 30j

Records et milestones :

Utilisateur le plus actif automatiquement suivi
Fonction la plus utilisée identifiée
Événements émis tous les 100 interactions

Événements émis :

NouvelleInteraction - À chaque action
NouveauRecord - Quand un utilisateur bat le record
MilestoneAtteint - Tous les 100 interactions

Le contrat est parfait pour suivre l'engagement des utilisateurs, créer des classements, ou simplement monitorer l'activité sans aucun fonds impliqué !
